# Projektna naloga pri Programiranju 2
Hana Lah, Tinkara Bostič

## Opis projekta

Delava igrico, navdih za katero je poznana igrica Geometry Dash, ki jo bova nadgradili z matematično zanimivimi objekti. V igrici igralec se poskuša izogniti oviram, ki se vedno hitreje premikajo proti njemu, tako se težavnost zvišuje.

## Navodila
Igrico se zažene v datoteki `main.rs` z gumbom **Run** oz. v ukazni vrstici z ukazom `cargo run`.
